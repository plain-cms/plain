Dunmere has a good many Victorian terraces with a geometric tiled hall under the carpet. Some need six tiles re-fixing and a deep clean. Some need half the floor relaid.

## How we price it

Every one of these floors is different, so there is no from-price. We lift the carpet with you, count what is loose and what is missing, and write the figure down the same week.

## New floors in old patterns

We also lay new geometric and encaustic floors in porches, halls and bathrooms. The pattern is set out from the centre of the room so the border is the same width all the way round.
