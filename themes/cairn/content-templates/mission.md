*This is the mission page, normally the home page (`content/pages/index.md`).
`hero: true` prints the panel: your headline, the one figure from
`data/impact.json` (`stat.number`, `stat.unit`, `stat.verb`, which read as
one phrase), this description as small print and the Donate button. Keep the
number to seven characters or fewer; write millions as 1.2M. Without a
number the panel is the headline alone.*

*A photograph is optional and is printed in the one ink. If you have one,
add a `heroImage:` line (a single person mid-task) and a `heroAlt:` line
describing it.
Delete these notes and set `draft: false` to publish.*
